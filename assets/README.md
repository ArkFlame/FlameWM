# Active assets

- `branding/`: FlameWM Start icon, wallpaper and wordmark from FlameWM Rust.
- `web/`: raw V8 prototype asset set, including the selected Breeze SVG subset and brand icons.
- `raster/`: pre-rasterized opaque RWRB/2 assets used by the embedded WebRender UI.
- `cursors/`: FlameWM Rust cursor assets for later real shell/session integration.

Runtime-critical asset licensing is retained under `LICENSES/` and inside source asset directories.
