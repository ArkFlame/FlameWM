# cmp-a11y: accessibility slices

## Slice: accessible name on audio popup back button

- Surface: `ui/shell/audio.html` (`#audio-back`), icon-only, previously no accessible name.
- Change: `aria-label="Back"` on the button.
- Test: `audio_back_button_has_accessible_name` in `crates/flamewm-shell/src/projection/audio.rs`.
- Verified: static HTML assertion only (unit test).
- Unverified: whether the compiled template and the accessibility bridge expose the name at runtime.

## Blocked (not attempted)

- Magnifier: needs compositor zoom pipeline and a design decision on zoom/follow behavior.
- Colour filters: needs compositor colour-matrix pass and design decision on filter set and persistence.
- Remaining screen-reader names: other icon-only controls across shell surfaces, and whether the
  UI compiler carries `aria-*` attributes into the accessibility tree at all (not established).
