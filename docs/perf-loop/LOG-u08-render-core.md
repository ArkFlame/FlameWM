# u08-render-core changes

- render-core/glyphs: text measurement (`advance_width`) sums the pen with `Font::metrics` and no `Vec`, no `Arc` clone, no rasterization; `caret_positions` shapes origins only; `char_index_at` streams the pen with zero allocation. Composition shift: every text measure in the software/Wayland path and the unscoped fallback drops two heap vectors, glyph mask clones and glyph rasterizations per call; layout re-measure and caret hit-testing get proportionally cheaper.
- render-core/text_layout: `collapse_whitespace` returns `Cow` and borrows the paragraph when it is already collapsed, so there is no `String` allocation or copy per paragraph per layout. Composition shift: removes one allocation per text paragraph on every relayout of unchanged text.
- render-x11/text_shadow_cache: borrowed `ShadowRef` lookup key through a new `ShadowKeyView` trait, mirroring `text_mask_cache`; `get` and `contains` hash the borrowed view and an owned `ShadowKey` is built only on a miss. Composition shift: removes two `String` allocations per text-shadow run per paint, which is hundreds to thousands of allocations per frame in shadowed chrome.
- render-core/soft: `SoftPixels` keeps a retained frame scratch (capped at 16 MiB, larger frames released) and overrides `paint_batch` through the new `apply_ops_in_place` and `apply_ops_to_scratch` helpers, so blur, backdrop and clipped-fill batches reuse one buffer instead of allocating a full frame per paint; the shared default batch path also skips the copy when every op is known infallible. Composition shift: no per-frame full-frame allocation in the software backend, with RAM bounded by the retain cap.
